# AI

## AI Model Integration

VC Hub provides the capability to integrate external AI models but does not include or provide any AI models itself.

Before using this feature, a suitable AI model must be purchased and configured separately.

The configured AI model can be used in the following areas:

1. **Admin Console – Script** <br> 
   Create and edit Service Functions and Shared Functions.<br>
   ![alt text](1.png)
2. **Editor – Events**<br>
   Create and edit scripts for pages or controls in the Event settings.<br>
   ![alt text](2.png)
3. **Control - HTML Viewer**<br>
   Generate HTML code.<br>
   ![alt text](3.png)

## AI Assistant

The AI Assistant helps users develop scripts and generate code based on natural-language requests. It is intended as an assistance tool and does not replace user review or validation.

- The AI Assistant does not execute generated code or make autonomous decisions.
Generated scripts are executed only after they have been reviewed and explicitly applied by the user.
- AI-generated content may be incorrect, incomplete, or unsafe. Always review and validate the generated content before use.
- The AI Assistant is not intended for safety-critical or production-critical purposes.
- If the AI Assistant is used in applications involving safety-critical functions, regulated products, or other compliance-sensitive scenarios, additional assessment and validation may be required to ensure that the overall solution complies with applicable regulatory and organizational requirements.
