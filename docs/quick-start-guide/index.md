# Quick Start Guide

The Quick Start Guide provides step-by-step instructions to help users get started with VC Hub. It covers the basic setup and configuration required to access and use the main functions of the system.

The guide provides two templates, one for the On-Premises version and one for the Cloud version. 

Select the template that matches your VC Hub version:

- [On-Premises](on-premises.md)  : For VC Hub installations deployed and managed in the customer's own environment.
- [Cloud](cloud.md): For VC Hub instances provided through the cloud platform.

**Note:** 

Some steps, configuration options, and prerequisites may differ between the two versions. Make sure to follow the instructions for the version you are using.
